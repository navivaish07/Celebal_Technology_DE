
# Week 05 - Apache Spark Assignment

## Overview

This repository contains the Week 05 assignment completed during the Celebal Technologies Data Engineering Internship.

The objective of this assignment is to learn the fundamentals of Apache Spark using PySpark and perform data cleaning, transformation, filtering, aggregation, and analysis on a CSV dataset.

---

## Objectives

- Learn Apache Spark Architecture
- Understand SparkSession and DataFrames
- Read CSV files using PySpark
- Perform Data Cleaning
- Handle Missing Values
- Remove Duplicate Records
- Apply Filtering Operations
- Perform Aggregations
- Use GroupBy Operations
- Save Processed Data
